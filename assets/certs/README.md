# TLS 证书（可选）

Wisp 默认按协议 v2.2 支持 HTTPS。把自签证书放在这里，接收服务就会自动走 TLS：

```
assets/certs/cert.pem   # 证书链（PEM）
assets/certs/key.pem    # 私钥（PEM，无口令）
```

没有这两个文件时，应用会自动退回 HTTP（仍然只在局域网内可达，不经过任何中继），
设置页的「加密传输」会显示「未找到证书，当前走明文 HTTP」。

## 生成自签证书

```bash
bash tools/gen_cert.sh
```

脚本会生成 10 年有效期的自签证书并写入本目录。首次启动时把两端的证书指纹互相确认一次，
之后就能靠指纹识别对端身份。

> 注意：自签证书无法被系统信任，这是局域网直连的常态。
> Wisp 的信任模型是"指纹 + 局域网"，而不是 CA 链——和 LocalSend 一致。
